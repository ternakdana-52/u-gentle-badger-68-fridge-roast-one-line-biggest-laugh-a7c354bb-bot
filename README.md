## The line

> My fridge texts me that the milk expired, which is brave for an appliance that has been holding it hostage since Tuesday.

(121 characters, one line.)

## How it works

`main.py` (Python 3, standard library only) writes exactly that line to
`/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
It validates the line first — 1–200 UTF-8 characters, single line,
non-whitespace, no control characters — then verifies the written file by
reading it back. Deterministic, no network, no randomness.

Run it:

```sh
python3 main.py
```
